Selected: phpmyadmin/sql-parser 6.0.1, greenlion/php-sql-parser v5.0.0, soundintheory/php-sql-parser 1.0, vimeo/php-mysql-engine 0.7.15, sad_spirit/pg_builder v3.3.1, flow-php/postgresql 0.48.0, flow-php/pg-query-ext 0.48.0, crodas/sql-parser v0.1.5, kwasii/laravel-sql-parser v0.1.0 and bleksak/sqlite-toolkit 1.0.4 parse both valid controls into structures that give the oracle summary. soundintheory is a 2013 fork of the Google Code predecessor of greenlion (shared PHP-SQL-Parser lineage, separate monolithic code: 54.3% of its normalized statements occur in greenlion v5.0.0). flow-php/pg-query-ext is a PHP C extension over libpg_query 18.0.0 (PostgreSQL grammar, shared family with the C libpg_query path): its coverage and AFL++ feedback come from LLVM-instrumented and allowlisted native sources (ext/pg_query.c, gram.c, scan.c, parser.c) in a source-built PHP 8.5.12, and its MIT licence is pinned from the flow-php/flow monorepo because the subtree-split archive has no LICENSE file. flow-php/postgresql is counted under the wrapper rule as a second path of the same libpg_query family: its sql_parse() calls the extension's pg_query_parse_protobuf() and decodes the tree into its own protoc-generated AST classes with the pure-PHP google/protobuf runtime, and its package PHP lines differ between the controls (Xdebug, 163 parse-time lines), while its native AFL++ tuples are those of the extension. vimeo/php-mysql-engine (312,980 lifetime downloads, rank 4) is an in-memory MySQL simulation for tests whose public SQLParser::parse() returns SelectQuery/InsertQuery objects; the harness calls the parser directly, never FakePdo, and cuts the input at the package SQLLexer's ';' lexemes because parse() reads one statement and rejects the terminator after INSERT or FROM. Its parser entry is documented only by its docblock-typed public class, not in the README (engine-with-public-parser precedent: DuckDB in the C++ cell). It is a PHP port of Slack's Hack SQL Fake and independent of the other selected code bases. kwasii/laravel-sql-parser (51 lifetime downloads, rank 9 of 10, a weak metric) is a PHP port of Python sqlglot 30.21.0 whose README-documented Dialect parse API returns sqlglot-style expression trees; it was found through the GitHub search and is also the 33rd hit of the Packagist 'sql parser' query. It requires illuminate/* for its Laravel integration; the harness calls only the parser core with sqlglot's base dialect. Its code is generated from or ported from sqlglot, so it shares design lineage with the Python sqlglot path, but it is independent of the other PHP code bases. bleksak/sqlite-toolkit (14 lifetime downloads, the weakest metric in the cell) is a hand-written SQLite 3.54 state-machine parser with its own typed AST; its README says most of the code was AI generated, and its parse entry is documented in docs/spec rather than the README. Ranking caveats: crodas/sql-parser has a weak metric (2,490 lifetime downloads). This is not a top-ten ranking. greenlion and soundintheory treat the whole input as one statement; pg_builder parses one statement per call, so its adapter cuts the input at its own Lexer's ';' tokens. Exclusions: greenlion forks (manticoresoftware, tsukasa, processfast, aitradeinc, michabbb, zent, rob-lester-jr04) share 84-99.6% of normalized statements with greenlion (zent 99.1%, rob-lester-jr04 99.6%) and are excluded as near-identical forks or older snapshots; this cut-off is a curation judgment. janfish and jtfnetoo copy phpMyAdmin 5.4.2 and v4.1.6 (99.9% and 100%), dottwatson copies vimeo (87.6%), and liquiddesign/php-sql-parser forks soundintheory (98.2% of normalized statements in soundintheory 1.0). sqlftw/sqlftw is proprietary. iamcal/sql-parser ranks higher but parses only CREATE TABLE schemas, and the doctrine, jdorn and nilportugues packages are formatters. Other plausible hits are a greenlion-based Laravel builder converter (rexshijaku/sql-to-laravel-builder), statement splitters and clause-string managers (nextras/multi-query-parser, rstoetter/csmartsqlstatement-php), schema-only parsers (calebdw/pg-schema-parser over pg_builder, maghead/sqlite-parser, DDL-only graze/morphism), an INSERT-only parser, a table-name extractor, consumers of selected parsers (cweiske/php-sqllint, pierresh/phpstan-pdo-mysql over the proprietary SQLFTW, bleksak/mago-pdo-extension, erkineren/sql-manipulator, fuwasegu/php-sql-snapshot, dottwatson/fpdo and other greenlion consumers), a lexer, a PDO mock, an EXPLAIN analyzer, a generator, a builder, a formula translator, packages without a tagged release, and slack/hack-sql-fake, which is Hack rather than PHP. Open leads: inilim/sqlite-parser was re-checked on 2026-11-18 and its only release still has no licence text; foolfish3/clickhousesqlparser also has no licence text in its release; subapp/sql stays blocked by Composer security advisories, which were not overridden; the WordPress MySQL-on-SQLite grammar parser (wordpress/mysql-on-sqlite) is not published on Packagist, so it has no primary metric.
