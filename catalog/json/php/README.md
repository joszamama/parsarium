# JSON / PHP — pilot

**Status:** pilot_ten_selected_search_bounded; incomplete. 10 verified third-party paths, 1 verified standard APIs, 10 verified Docker harnesses.

Ten PHP JSON third-party paths passed valid nested object controls and source-line coverage. Laminas, JSON Machine, salsify, pcrov and the five paths from the supplemental queries (boundwize/jsonrecast, laktak/hjson, klkvsk/json-decode-stream, eftec/services_json, joelwurtz/json-stream-polyfill) also passed a valid nested array control and stable source-line AFL feedback. Laminas is abandoned, and its own decoder runs only when explicitly enabled; its default API route delegates to ext/json. JSON Machine shares ext/json for member decoding. salsify accepts only object/array roots and silently accepts concatenated documents, so its harness rejects anything other than one complete document; the tree-building listener is harness code. The ten-path ceiling was filled by the highest-download undecided own-parser lead, joelwurtz/json-stream-polyfill; a source re-scan of the undecided hits ranked above it (networkteam/json-seq, midnite81/json-parser, clue/ndjson-react, nathanmac/parser, elgentos/parser, fastd/config) found only json_decode calls. Lower-download supplemental hits, including adrienbrault/partial-json, tdt/json and hiroto-k/json5-php, were not inspected because the ceiling was reached. bcncommerce/json-stream (lossy Reader, identical package lines on both controls) and symfony/json-streamer (a schema-free read is one json_decode call) are excluded after pinned probes; salsify forks and listener wrappers and json_decode wrappers, including colinodell/json5 on both valid controls, are excluded. pcrov/jsonreader has a separate lexer and state machine, with three parser-source features and AFL tuples differing between the valid controls. boundwize/jsonrecast builds a formatting-preserving AST with its own lexer and recursive-descent parser; string escapes are ext/json on single tokens, and most of its 35-line control differential is in the indentation-detection pass that parse() runs. laktak/hjson parses a JSON superset and is counted only for valid JSON; it drops an empty member name and lets duplicates overwrite by source reading. klkvsk/json-decode-stream unescapes string tokens with ext/json and accepts concatenated documents, which its adapter rejects. eftec/services_json returns null rather than an error for text it cannot reduce, and its control differential is 4 lines. joelwurtz/json-stream-polyfill (version 0.1.0, first released 2026) scans structure in PHP but decodes every key, string, number and literal token with one json_decode call, so scalar values share ext/json; its harness walks the lazy Documents and never calls toValue(), which would decode a whole container with ext/json. Its control differential is 1 line and 1 AFL++ tuple (escaped-quote backslash handling in the string-end scanner, present only in the object control), the smallest among the selected PHP JSON paths. The bounded search used thirteen Packagist queries of at most 100 hits each: five captured at 03:23 UTC and eight supplemental queries (json stream, json5, jsonc, json lexer, json tokenizer, json reader, hjson, json pull parser) captured at 15:19 UTC. Packagist matches json5, jsonc and hjson loosely, so their first 100 hits are mostly generic JSON packages. Rankings use the 03:23 download values, which cover every selected path. Package downloads measure overall/historical adoption, not JSON parsing frequency. Valid controls do not establish complete RFC 8259 support.
