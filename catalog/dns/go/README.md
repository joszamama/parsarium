The symbol searches found github.com/shadowy-pycoder/mshark/layers (selected: the DNS layer of a packet analyzer, its own decoder). Exclusions from those routes: shuLhan/share lib/dns (own decoder but no exported way to pass message bytes), soypat/seqs eth/dns and nadoo/glider dns (RDATA kept raw, the dnstt precedent), tachyon udwDnsPacket (drops classes and merges sections), gonq (header only), v2ray protocol/dns and coroot's l7 (x/net dnsmessage), likexian/doh (JSON types), winstonprivacyinc/dns (benburkert/dns copy) and five miekg/dns snapshots or clones (Psiphon-Labs/Psiphon-Inc, tonnerre, cloudflare, AZ-X; 81-100% of their lines in a miekg/dns revision); the other symbol hits were vendored miekg/dns copies, DNS-provider APIs or zone tools recognized by path and not opened. Limits: gopacket's and mshark's counts cover their whole multi-protocol layers packages. The standard library exports no DNS message parser (its net resolver vendors x/net dnsmessage without exporting it). Each verified path parses the two valid controls (a query and a response with compressed CNAME/A/AAAA/MX answers) to the hand-written oracle summary, has library source coverage and stable AFL++ feedback that differs between the controls. Two valid controls do not establish EDNS0, DNSSEC, TXT, authority/additional or malformed-input behavior. Package-level adoption metrics include non-DNS use, and the cell is not a definitive top ten.
