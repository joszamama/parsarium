# DNS / Go — pilot

**Status:** pilot_nine_verified_search_bounded; incomplete. 9 verified third-party paths, 0 verified standard APIs, 9 verified Docker harnesses.

Pilot cell: nine Go paths verified (github.com/miekg/dns, github.com/google/gopacket/layers, golang.org/x/net/dns/dnsmessage, codeberg.org/miekg/dns, github.com/benburkert/dns, github.com/phuslu/fastdns, github.com/cznic/dns/msg, github.com/mateusz834/dnsmsg, tangled.sh/seiso.moe/magna), ranked by pkg.go.dev Imported by package count. Remaining leads: www.bamsoftware.com/git/dnstt.git/dns (unresolved_control_failure), github.com/cybergarage/go-mdns/mdns/dns (unresolved_control_failure). Excluded after checking: github.com/coredns/coredns/plugin/pkg/dnsutil, github.com/gopacket/gopacket/layers, github.com/zmap/dns, github.com/mr-torgue/dns, github.com/pion/mdns, github.com/ncruces/go-dns, github.com/eycorsican/go-tun2socks/common/dns, github.com/hashicorp/mdns, github.com/micro/mdns, github.com/whyrusleeping/mdns, github.com/pion/mdns/v2, github.com/cznic/dns/rr, github.com/asciimoth/gonnect/dns, github.com/bassosimone/dnscodec, github.com/bassosimone/minest, github.com/dmachard/go-netutils, github.com/xtls/xray-core/transport/internet/finalmask/xdns, github.com/Packet-Clearing-House/DNSAuth/libs/dnsdist, github.com/presotto/go-mdns-sd/go_dns (reasons in leads.json). Round 3 added pkg.go.dev searches with the same surface and metric (dns wire, dns codec, dns decode, dns unpack, dnsmessage, mdns, dns rr; first 100 each, under round3_search in the snapshot). The positive-count hits that were opened (the three most-imported mDNS libraries, pion/mdns/v2, codec, wire and tunnel helpers listed in leads.json) either wrap an already selected decoder (miekg/dns, x/net dnsmessage, gopacket, cznic/dns), copy the dnstt control failure, or are not wire parsers; the remaining round-3 hits are mostly go-micro/libp2p service-discovery registry plugins and forks, recognised by package path and not opened. The one new family found (a copy of Go's old net/dnsmsg.go inside go-mdns-sd) has no known importers. Round 3 therefore ended at eight. Round 4 searched beyond the registry windows (registry-snapshot.json round4_discovery): GitHub repository searches (dns parser, dns packet, dns message, topic:dns, rfc1035, dns codec, dns decoder, dns wire format; first 100 each, library-like hits looked up on pkg.go.dev), awesome lists, reverse dependencies and forks of the selected decoders, and binary-format decoder tools, ranked only by the same pkg.go.dev count (round4_targeted). It found github.com/mateusz834/dnsmsg (selected: an incremental parser whose code shares 7.0% of its distinct lines with x/net dnsmessage). Excluded: github.com/mjl-/adns (net resolver fork over x/net dnsmessage), github.com/irai/packet and github.com/alabianca/dnsPacket (response control fails by source inspection: MX not decoded), github.com/niclabs/dnszeppelin (capture library over miekg/dns), github.com/getlantern/dns (94.2% miekg/dns fork), and decoders with no known importers (go-dnscollector dnsutils, fq's format/dns). The cell stays at nine: no further Go package with a positive pkg.go.dev importer count and its own documented message-bytes decoder was found. gopacket's count covers its whole multi-protocol layers package. The standard library exports no DNS message parser (its net resolver vendors x/net dnsmessage without exporting it). Each verified path parses the two valid controls (a query and a response with compressed CNAME/A/AAAA/MX answers) to the hand-written oracle summary, has library source coverage and stable AFL++ feedback that differs between the controls. Two valid controls do not establish EDNS0, DNSSEC, TXT, authority/additional or malformed-input behaviour. Package-level adoption metrics include non-DNS use, and the cell is not a definitive top ten.
