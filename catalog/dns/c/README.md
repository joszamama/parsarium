# DNS / C — pilot

**Status:** pilot_six_verified_search_bounded; incomplete. 6 verified third-party paths, 1 verified standard APIs, 6 verified Docker harnesses.

Pilot cell: six C paths verified. c-ares, ldns, knot (libknot), udns and getdns are ranked by Debian popcon sourcemax installations from the pinned table; William Ahern's dns.c (wahern-dns, rel-20160808, 273 GitHub stars) fills a sixth slot under the 2026-11-18 star-fallback rule for C and C++ cells and is ranked separately by stars, after every Debian-ranked path. The cell stays below ten because no further C library with a documented API for caller-supplied message bytes, a Debian metric or at least 100 stars on a tagged upstream release, decodes the controls. Selected paths: getdns bundles gldns (Unbound's sldns, ldns lineage), but its own decoder files share 75 of 3,228 distinct normalized source lines (2.3%) with ldns 1.8.4, so it is kept as a distinct package API with the lineage stated. dns.c passes both controls through its public packet API (dns_p_study, dns_rr_grep, dns_any_parse); its documentation is the README, the public dns.h declarations and the release's own parse-packet command, since the TeX guide does not cover the packet API. glibc libresolv ns_initparse/ns_parserr is verified on both controls as a standard/runtime path (not instrumented, no AFL++ feedback, outside the ranking); musl was not run. Field caveats: c-ares, ldns and udns drop the reserved Z bit (z carries AD and CD); knot and getdns report all three bits; dns.c keeps the three bits after RA in one field, so z carries Z, AD and CD. Harness-side RDATA formatting (lower-casing, joining the MX preference and exchange) is disclosed per path. Debian and Conan exclusions (registry-snapshot.json round2_targeted and round3_search; all 128 debian-source:dns names in the pinned table were read, beyond the first 100 recorded by the bounded search): libmicrodns, libjdns and djbdns have no documented message-bytes API or no library, and adns, unbound, bind9, libevent and libspf2 are excluded as well; dnsjit (popcon 4) stays unresolved because its parser is a Lua module inside the dnsjit engine with no linkable C library; Conan-only mdns and pro-mdnsd have no primary metric (see the star-fallback search below). mdnsd's libmdnsd message_parse is public but leaves MX RDATA raw (control failure); avahi and systemd keep their packet code internal; wireshark, libpcap, libnet, libtrace3 and ndpi are capture, construction or classification libraries without a documented message decoder; sofia-sip, lwip and ruli are resolvers; knot-resolver parses with the selected libknot; libowfat carries djbdns's primitives. Search beyond the registry windows (registry-snapshot.json round4_discovery): GitHub repository searches for C (dns parser, dns packet, dns message, topic:dns, rfc1035, dns codec, dns decoder, dns wire format; first 100 each), Debian, Fedora and Alpine package lists for libraries with an exported or bundled DNS decoder, and awesome lists, with popcon values from the same pinned table (round4_targeted). GNUnet's documented GNUNET_DNSPARSER_parse (popcon 58) stays a lead because it stores each record's TTL as a wall-clock expiration time, so the controls' TTLs cannot be read back from its parse without harness clock arithmetic; YADIFA's libyadifa-dev ships headers only with no API reference. Mongoose (no TTL, one answer) and pjproject (MX RDATA raw; Debian experimental only) fail the response control by source inspection; belle-sip, lua-cqueues, rspamd and opensmtpd keep their DNS code internal or Lua-only. The GitHub-only libraries found there (firedns, s6-dns, wdns, dnsparse) have no Debian source package and so no primary metric; the Debian dev-package fallback does not apply to any of them. Star-fallback search (registry-snapshot.json round_6_star_fallback): twelve GitHub repository searches restricted to language:C and stars:>=100 (first 100 hits each), with stars, fork flags and tags captured from the GitHub REST API; dns.c is the one path selected from them. mjansson/mdns (598 stars) is excluded because it decodes messages only inside its socket receive functions and has no MX decoder; simdzone is a zone-file parser; s6-dns (47), SPCDNS (84), mdnsd (75), dnsparse (24), wdns (20), firedns (18) and the pro-mdnsd fork (11) are below 100 stars; the other hits are servers, proxies, tunnels and tools. Limits: each verified path parses the two valid controls (a query and a response with compressed CNAME/A/AAAA/MX answers) to the hand-written oracle summary, has library source coverage and stable AFL++ feedback that differs between the controls. Two valid controls do not establish EDNS0, DNSSEC, TXT, authority/additional or malformed-input behavior. Popcon counts are package-level, include non-DNS use and are small below c-ares; GitHub stars measure repository interest, not downloads, and are not comparable to popcon; the cell is not a definitive top ten.
