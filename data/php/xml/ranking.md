# PHP × XML: selected parsers (pilot)

7 control-verified third-party paths selected. The ceiling is ten. PROTOCOL.md lets a wrapper qualify as a package API with its parser family identified, so libxml2-family wrappers are not excluded for that reason alone. Remaining lower-ranked wrappers stay unresolved until qualified and tested; prewk/xml-string-streamer was excluded by a valid-control probe.
