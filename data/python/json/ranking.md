# Python × JSON: pilot ranking

Five third-party paths are control verified so far; nine targeted documentation leads were recorded, and four remain unverified. The ten-path ceiling is not a quota. The bounded PyPI Simple Index search is pending, so this is not a claim about the definitive most-used JSON parsers.

The comparable within-cell signal is [PyPI Stats](https://pypistats.org/api/) `last_month` package downloads excluding known mirrors, observed 2026-11-17 around 02:24 UTC. It measures adoption of entire packages, including transitive installs and uses unrelated to JSON parsing. Unverified leads with higher download counts are recorded in [leads.json](leads.json) but are not ranked as verified parsers.

The standalone `jiter` package has 421,162,504 last-month downloads in the lead log. It shares Pydantic's Jiter parser family but is not a verified package path here. All five selected paths have pinned container controls, parser-scoped coverage, and AFL++ feedback. The [Pydantic native receipt](pydantic-valid-feedback.json) checks repeated, input-dependent Jiter source regions on two valid controls. The [orjson receipt](orjson-valid-feedback.json) records 114 differing Rust deserializer features and AFL++ tuples between those controls; vendored yyjson C syntax-parser source is outside that coverage. The [ijson receipt](ijson-valid-feedback.json) records stable valid-control differential in its own C extension and pinned YAJL C tokenizer. Its source-built embedded YAJL -O0 route differs from the official Linux wheel’s linkage and optimisation, and other backends are untested. The [ujson receipt](ujson-valid-feedback.json) checks that `ujson.loads` on bytes and on text gives the exact type-tagged tree of an independent CPython `json` oracle for both controls, and records stable differential feedback in `decode.c` and double-conversion C++. Duplicate keys (last wins), integer overflow to arbitrary precision and the non-RFC `NaN`/`Infinity` tokens are documented from source only. The simplejson metric is retained in the dated [lead snapshot](leads.json). The [CPython `json` standard API](standard.json) is recorded separately, without a third-party popularity rank.

The Pydantic LLVM export warned about mismatched profile data in 99 whole-extension functions. Its coverage claim is limited to the scoped Jiter regions recorded in the verification receipt; complete extension coverage is not established.
