# Python × TOML: pilot ranking

Two third-party paths are control verified. This is a bounded pilot cell, not a claim about the most-used TOML parsers. The leads came from targeted PyPI and PyPI Stats lookups beside one bounded [PyPI Simple index name search](registry-snapshot.json) (first 100 alphabetical hits of 409), because that index has no relevance order.

The within-cell metric is [PyPI Stats](https://pypistats.org/api/) `last_month` package downloads excluding known mirrors, captured 2026-11-17 in the [registry snapshot](registry-snapshot.json). It counts whole-package installs, including transitive installs and uses unrelated to parsing.

| Rank | Package | Release | Metric | Parsed scope | Parser family |
| ---: | --- | --- | ---: | --- | --- |
| 1 | [tomlkit](https://github.com/python-poetry/tomlkit/blob/0.15.2/docs/api.rst) | 0.15.2 | 591,365,129 | TOML 1.0.0 document from local text via `tomlkit.parse`, walked by tomlkit item type with each scalar unwrapped | tomlkit pure-Python style-preserving recursive-descent parser (`parser.py` over `source.py`) |
| 2 | [tomli](https://github.com/hukkin/tomli/blob/2.5.0/README.md) | 2.5.0 | 263,305,223 | TOML 1.0.0 document from local text via `tomli.loads` (plain dict) | tomli pure-Python parser (`_parser.py`, `_re.py`); same family as the standard `tomllib` |

Both paths give the exact hand-written typed tree of both controls ([service-config](../../../controls/toml/service-config.toml) and [typed-scalars](../../../controls/toml/typed-scalars.toml)) on every API mode tried, and CPython `tomllib` in the same image gives the same trees. The [tomlkit receipt](tomlkit-valid-feedback.json) covers 845 package lines on the primary control (408 in `parser.py`); three runs per control give identical feedback, and the controls differ by 404 source lines and 401 AFL++ tuples. tomlkit keeps comments and formatting in its items; only parsed values are compared. Its downloads mostly reflect Poetry and other build tools. The [tomli receipt](tomli-valid-feedback.json) covers 284 lines (259 in `_parser.py`, 25 in `_re.py`); the controls differ by 137 source lines and 137 AFL++ tuples. CPython's `tomllib` is a vendored copy of tomli, so tomli and the [standard API](standard.json) are one family, not independent parsers; the hand-written trees are tomli's independent check. Only tomli's pure-Python wheel is measured, not the mypyc-compiled wheels that pip prefers where they exist. tomlkit and tomli are independent code bases.

Unverified leads ([leads.json](leads.json)): toml 0.10.2 (145,147,540) fails the typed-scalars control, because `toml.loads` returns `datetime.time(0, 32)` for the local time `00:32:00.25` and drops its fractional seconds; the service-config control matches. rtoml 0.14.0 (1,380,894) is a PyO3 extension over the Rust toml crate and was not attempted, since a path would need a source build with Rust parser coverage. pytoml (337,081), pytomlpp (43,243), toml-rs (18,062) and qtoml (2,002) were not run. tomli-w (85,996,374) is excluded as a writer.
