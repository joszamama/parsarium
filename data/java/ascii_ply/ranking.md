The metric is deps.dev's known public direct dependents for each exact Maven release, a limited within-Java adoption proxy. It does not measure PLY-specific use, and zero can reflect coverage or version-age gaps. LWJGL Assimp, MonkeyWrench, and JAssimp share the native Assimp PLY parser family with the C++ Assimp path.

Its documented `PlyReader.read(InputStream)` returned parsed vertices and face indices from the local control. Maven artifacts, tagged README and MIT license are hash-pinned. deps.dev reports zero known public direct dependents for this exact release, so the rank is tied with the other zero-count packages and does not establish broad adoption.
