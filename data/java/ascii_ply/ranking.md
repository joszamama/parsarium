Its documented `PlyReader.read(InputStream)` returned parsed vertices and face indices from the local control. Maven artifacts, tagged README and MIT license are hash-pinned. deps.dev reports zero known public direct dependents for this exact release, so the rank is tied with the other zero-count packages and does not establish broad adoption. Six more qualifying paths are needed for the working target.
