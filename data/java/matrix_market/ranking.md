# Java × Matrix Market: verified parser ranking

Eight verified third-party package paths: six Maven artifacts, one official tagged Java library distribution, and one tagged source-built framework path; working goal 20, ceiling 30. The metric is deps.dev's exact-release public direct dependent count. It is a partial within-Java adoption proxy and does not measure Matrix Market-specific use. Three Matrix Market string searches returned zero hits; a broad EJML search returned 28 package-name leads. A separate GitHub code search inspected the first 100 of 378 Matrix Market banner hits. MTJ, SystemDS, la4j, Smile, MeteoInfo, Drop-seq, and GraphTea came from targeted publisher source or documentation. Search hits are not parser evidence.
