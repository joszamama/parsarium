# JAVA × TOML: selected parsers (pilot)

5 control-verified third-party package/API paths selected: jackson-dataformat-toml (293), tomlj (133), night-config-toml (77), jtoml (53), ktoml-core (28). The ceiling is ten; this pilot ranks verified paths only and does not pad the selection. The five paths are separate parser families. jackson-dataformat-toml has its own JFlex lexer and parser but builds a jackson-databind JsonNode tree, so it shares jackson-core/jackson-databind 2.23.0 with the Java JSON cell's Jackson paths.

Both fixed controls ([service-config.toml](../../../controls/toml/service-config.toml) and [typed-scalars.toml](../../../controls/toml/typed-scalars.toml)) produce the expected typed trees for all five paths. Coverage and AFL++ feedback are scoped to each library's own TOML package ([afl-feedback.json](afl-feedback.json)).

jtoml 1.8.3 ([sources](https://repo.maven.apache.org/maven2/io/github/wasabithumb/jtoml/1.8.3/jtoml-1.8.3-sources.jar), Apache-2.0) reads the file with `JToml.jToml().read(Path)`; every scalar kind comes from `TomlPrimitive`'s typed accessors. JaCoCo covers 1,085 lines of the three jtoml release source jars on service-config and 1,172 on typed-scalars; the parser-line AFL++ bridge gives 1,094 and 1,179 tuples (349 differ) with three identical repeats per control.

ktoml-core 0.7.1 ([sources](https://repo.maven.apache.org/maven2/com/akuleshov7/ktoml-core-jvm/0.7.1/ktoml-core-jvm-0.7.1-sources.jar), MIT) is a Kotlin multiplatform library; the harness uses the JVM artifact ktoml-core-jvm and the runtime versions its release POM declares. `TomlParser` is a Kotlin `@JvmInline` value class, so the documented `TomlParser(TomlInputConfig()).parseString(text)` compiles to the public static `TomlParser.parseString-impl(TomlInputConfig, String)`, which the Java adapter calls by reflection. Table keys come from `TomlNode.getName()`, the name ktoml's own decoders match; `getKey().last()` would turn `site."example.com"` into `com` because the parser re-splits the key after moving its prefix into a synthetic table. Integer and float come from the `TomlLong`/`TomlDouble` node classes and the four date-time kinds from the `TomlDateTime` content class. JaCoCo covers 602 lines of the ktoml-core-jvm sources jar on service-config and 562 on typed-scalars (three kotlin-stdlib inline lambda classes compiled into ktoml's packages are left out); the parser-line AFL++ bridge gives 620 and 582 tuples (316 differ) with three identical repeats per control. The metric is the multiplatform root coordinate `com.akuleshov7:ktoml-core`; the separately published `ktoml-core-jvm` coordinate (68) is not added.
