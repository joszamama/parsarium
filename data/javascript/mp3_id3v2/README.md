# Compatibility paths for MP3 projects verified on the ID3v2-tagged control

These links point into [`../mp3/`](../mp3/), the merged MP3 cell for this ecosystem. Pinned project manifests under `projects/mp3_id3v2/` record these paths, and their receipts hash the manifests, so the paths stay valid until those projects are moved and re-verified. This directory is not a catalog cell.
