# MP3 targets verified on the ID3v2-tagged control

These projects belong to the single [MP3 format](../../catalog/mp3/README.md). They were
verified on the ID3v2-tagged MP3 control and keep this directory, and the `mp3_id3v2`
target name in commands such as `parsarium run mp3_id3v2 java jaudiotagger ...`,
because their pinned manifests and receipts record these paths. The
[MP3 runnable targets](../mp3/README.md) list every MP3 target, including these.
