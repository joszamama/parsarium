WHOLE FORMAT

Replay across the collection.

run-format selects every fully verified Docker target for PNG. There are 153 currently verified targets for this format. By default, each target receives its own known-valid control. Give it one file to see how the same input behaves across parsers.

Each target writes a separate receipt. The batch writes summary.json with the target count and outcome totals. Try three targets first; a full run can take time and Docker storage proportional to the target count.

Add --ecosystem python to narrow the set. --list previews the selected targets without starting Docker.

SEE THE VERIFIED TARGETSpython3 parsarium.py run-format png --list
FIRST TRY: THREE TARGETSpython3 parsarium.py run-format png --limit 3 --results runs/png-first-3
RUN EACH PINNED CONTROLpython3 parsarium.py run-format png --results runs/png-controls
RUN ONE FILE ACROSS TARGETSpython3 parsarium.py run-format png --file INPUT_FILE --results runs/png-my-file
