EJECUTAR LOCALMENTE

Ejecuta un objetivo. Luego, todo el conjunto.

Cada ruta ejecutable tiene un harness Docker fijado. Empieza con un parser y su control válido; después, repite una entrada en todos los objetivos verificados de un formato.

Un objetivo ↓Todo un formato ↓

ANTES DE EMPEZAR

Obtén la colección.

Instala e inicia Docker y clona el repositorio. Ejecuta los comandos de esta página desde la raíz del repositorio. La web muestra evidencia guardada; tu ordenador ejecuta la biblioteca real.

TERMINALgit clone https://github.com/joszamama/parsarium.git && cd parsarium

Sigue un parser de principio a fin.

Elige un formato. El objetivo destacado muestra su API de entrada, un control fijado, un comando para tu archivo, la reproducción de un corpus y la preparación de AFL++.

TODO UN FORMATO

Repite la entrada en la colección.

run-format selecciona todos los objetivos Docker plenamente verificados de PNG. Hay 153 objetivos verificados para este formato. Por defecto, cada uno recibe su propio control válido. Añade un archivo para comparar la misma entrada entre parsers.

Cada objetivo guarda un registro separado. El lote escribe summary.json con el número de objetivos y los resultados. Prueba primero con tres; una ejecución completa puede necesitar tiempo y espacio Docker proporcionales al número de objetivos.

Añade --ecosystem python para limitar el conjunto. --list muestra los objetivos seleccionados sin iniciar Docker.

VER LOS OBJETIVOS VERIFICADOSpython3 parsarium.py run-format png --list
PRIMERA PRUEBA: TRES OBJETIVOSpython3 parsarium.py run-format png --limit 3 --results runs/png-first-3
EJECUTAR CADA CONTROL FIJADOpython3 parsarium.py run-format png --results runs/png-controls
UN ARCHIVO EN TODOS LOS OBJETIVOSpython3 parsarium.py run-format png --file INPUT_FILE --results runs/png-my-file
Qué se guardaruns/png-controls/
