0x0020uso

Tres formas de usarlo.

Instala el comando con pip. Necesita Python 3.11, y Docker para ejecutar targets. La primera ejecución descarga los archivos de los harnesses de tu versión, unos 19 MB.

$ pip install parsarium

Pasa un archivo por un parser.

Obtienes un registro JSON con el hash de la entrada, el ID de la imagen, el código de salida y el tiempo que tardó. Es la forma más rápida de comprobar cómo trata una biblioteca concreta una entrada concreta.

$ parsarium show png python pillow
$ parsarium run png python pillow my.png

Envía el mismo archivo a todos los parsers.

Cada target escribe su propio registro y summary.json los reúne. Cuando los parsers no se ponen de acuerdo sobre los mismos bytes, ahí es donde conviene empezar a mirar.

$ parsarium run-format png --list
$ parsarium run-format png \
    --file my.png --results runs/png-my-file

Haz fuzzing a un parser con AFL++.

Todos los targets ejecutables tienen una imagen para AFL++. Los parsers en C, C++ y Rust se instrumentan directamente. Los parsers en Go, Java, JavaScript, Python y PHP envían su cobertura a AFL++ mediante un pequeño puente.

$ parsarium afl build png python pillow
$ parsarium afl prepare png python pillow runs/pillow
$ parsarium afl run runs/pillow --seconds 3600

0x0030motores

Los paquetes y los motores que hay detrás.

Muchos paquetes son wrappers del mismo decodificador. En PHP, la mayoría de los paquetes de PNG leen imágenes a través de GD; en JavaScript, la mayoría de los paquetes de PDF se apoyan en pdf.js. Parsarium registra la familia de parser de cada entrada, así que tú decides qué contar.

Un estudio sobre ecosistemas necesitará todos los paquetes. Un estudio sobre motores de parsing, un target por familia. El banco construye cualquiera de las dos selecciones y le asigna un ID que puedes citar en un artículo.

0x0050acerca de

Por qué existe.

Soy Pepe Zamudio, doctorando en CISPA. Trabajo en fuzzing y generación de pruebas para programas con entradas complejas. Cada estudio que hacía empezaba igual: elegir parsers, instalarlos y escribir adaptadores. Parsarium es ese trabajo hecho una vez, con cuidado, y compartido, para que los experimentos partan de los mismos targets y sus resultados se puedan comparar.
