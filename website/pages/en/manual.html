0x0000manual

Testing parsers, from one file to a thousand targets.

These chapters are my working notes on parser testing, written so I can come back to them and so others can learn from them. They start with what a parser does with its input and end with how to design an experiment across many targets. Every chapter ends with the key ideas, a five-question quiz, and three exercises on Parsarium, from warm-up to challenge, each with a hint and a solution. Your progress is saved in this browser.

0x0020setup

Before the exercises.

You need Python 3.11 or newer and Docker. Browsing the catalog only needs Python; running harnesses needs Docker with Linux amd64 and arm64 support. Clone the repository and run every command from its root.

$ git clone https://github.com/joszamama/parsarium
$ cd parsarium
$ python3 parsarium.py list
