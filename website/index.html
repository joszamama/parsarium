INPUT GENERATION MEETS PARSER EXECUTION

The file is
the handoff.

For PNG, Fanbase supplies a Fandango spec that generates complete PNG files. Parsarium replays that directory through a chosen parser and records each run. Other formats can use an available Fanbase spec, a custom spec, or any corpus of files.

Get the harnesses ↗
PNG example / generator → files → parser
# Fandango writes 100 complete PNG files
$ fandango fuzz -F png -n 100 -d generated/png
# Parsarium runs those files through libpng
$ python3 parsarium.py replay png c libpng \
    generated/png runs/png-replay \
    --generator Fandango --spec png
# results go to runs/png-replay/
