TAKE IT TO THE TERMINAL

Bring your
own inputs.

Use a verified control to start. Then replay a generated corpus or prepare AFL++ on the same parser target.

Get the harnesses ↗
parsarium / same target, different inputs
# run one file
$ python3 parsarium.py run png c libpng \
    controls/png/red-green.png
# replay inputs from a generator
$ python3 parsarium.py replay png c libpng \
    generated/png runs/png-replay \
    --generator Fandango --spec png
# prepare the same target for AFL++
$ python3 parsarium.py afl build png c libpng
$ python3 parsarium.py afl prepare png c libpng \
    runs/png-afl
