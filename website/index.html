05 / THE METHOD

A name is a lead.
A parse is proof.

Parsarium keeps discovery, verification, and runnable harnesses distinct so the collection says exactly what has been checked.

01
⌕

Find a lead

Search registries and project docs for packages that claim to read a format. A search hit alone does not enter the catalog.

02
✓

Make it parse

Pin an open-source release, point to a local input API, and record a valid control with an observable format-aware result.

03
▣

Run it again

Selected entries have container harnesses and coverage instrumentation. Every cell has at least one runnable project.
